# No accounts, no server

**Choice:** Streaks has no accounts and no backend; habit data stays on the device ([[offline-first]]).
**Why:** privacy is the product's promise, and a server is a bill and an on-call duty for a one-person team.
**Rejected:** sharing, sync and leaderboards, which all need a server.
