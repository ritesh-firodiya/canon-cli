A real verdict

What a push back looks like.

The request asked for a manual entry button, "because users keep asking".

The gate found a decision against manual entry, no feedback on file, and no retention metric.

So it stopped and gave three ways on: bring the facts, change the rule on written terms, or drop it.

Without zeno, this would have been built, then argued about in review.

Where the time goes

Find the conflict before the code, not after.

The later a conflict is found, the more work sits on top of it. The pilot counts how many conflicts the gate catches before code.
