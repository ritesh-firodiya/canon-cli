# .context

canon-cli's own product material, written in Plain Context.

## Start here

1. [`wiki/concepts/purpose.md`](wiki/concepts/purpose.md): what canon is, who it is for, what it is not.
2. [`wiki/concepts/glossary.md`](wiki/concepts/glossary.md): canon's own words.
3. [`ops/run.md`](ops/run.md): how to run, test and release it.
4. [`wiki/index.md`](wiki/index.md): every decision, one line each.
5. [`tasks.md`](tasks.md): what to do next. The top item of `## Now` comes first.

The rules canon ships: [`standards/constitution.md`](../standards/constitution.md), then
Plain Context ([`context.md`](../standards/context.md) and [`writing.md`](../standards/writing.md)).

## Where things are

| Folder | Holds |
|---|---|
| `wiki/` | What an agent would get wrong without being told: concepts, decisions, research |
| `problems/` · `ideas/` · `plans/` · `features/` · `bugs/` | Open and shipped work records |
| `architecture/` | How canon is built and what it costs (`architecture.json`) |
| `designs/` | The band's design |
| `metrics/` | Metric definitions and monthly history |
| `ops/` | How to run, test and release |

Closed records are deleted once their lesson is in a decision page; git
keeps them.
