# .context

canon-cli's own product material, in canon's context layout.

## Start here

1. [`tasks.md`](tasks.md): what to do next. The top item of `## Now` comes first.
2. [`wiki/concepts/purpose.md`](wiki/concepts/purpose.md): what canon is for and how its parts fit.
3. [`wiki/index.md`](wiki/index.md): every decision, one line each.

## Where things are

| Folder | Holds |
|---|---|
| `wiki/` | What an agent would get wrong without being told: concepts, decisions, research |
| `problems/` · `ideas/` · `plans/` · `features/` · `bugs/` | Open and shipped work records |
| `architecture/` | How canon is built and what it costs (`architecture.json`) |
| `designs/` | The band's design |
| `metrics/` | Metric definitions and monthly history |
| `ops/` | How to release |

The rules canon ships to every repo are not here. They are in `standards/` at the
repo root. Closed records are deleted once their lesson is in a decision page; git
keeps them.
